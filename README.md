# Notes Generator

This project provides two note templates that can be filled in through a web form and copied to the clipboard.

## Templates
1. **Daily Notes**
   - Fields: Acc#, Case, Affected Domain, Customer's Name, Authentication, Jarvis URL, Issue, Steps Taken.
2. **Escalation**
   - Fields: What needs fixing, Error Message, When did the issue start, What was changed, Steps to replicate, Steps 1-3, Additional Notes.

## Usage
- Open [index.html](index.html).
- Select **Daily Notes** or **Escalation**.
- Fill in the form and click **Generate Note**.
- Copy the generated note using the **Copy to Clipboard** button.

## Deployment
To deploy with GitHub Pages:
1. Push this repo to GitHub.
2. Go to **Settings > Pages**.
3. Under "Build and deployment", set the branch to **main** and the folder to **/ (root)**.
4. Save.  
   Your site will be live at: `https://username.github.io/repo-name/`
